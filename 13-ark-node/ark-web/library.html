What the library holds

Every collection this node knows about: which ones an answer can cite, which you can only browse, and which are not on this drive yet. Each one says why it is in its state, and what to do if you want to change that.

This node never downloads anything by itself. To add a collection, run the command shown on its card on this computer, at a time when it has internet. A download is browsable as soon as it finishes; answers can cite it only after it is indexed, which uses the graphics card and takes from minutes to many hours depending on its size.
